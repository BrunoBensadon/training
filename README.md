# training

Online tools supporting training delivery, mostly for
[CISV International](https://cisv.org) — a peace-education NGO running
volunteer-led leadership training across 60+ countries.

One GitHub Pages site, each tool under its own path.

Licensing is split: code under [MIT](LICENSE), content — items, copy,
facilitator materials, docs — under [CC BY-SA 4.0](LICENSE-CONTENT). See
`docs/DECISIONS.md` for why, and note that the split has not yet been
agreed with CISV International.
